# Wazuh-Home-Lab
A hands-on Wazuh SIEM lab for threat detection, log analysis, and incident response using Windows, Linux, Sysmon, Suricata, and custom detection rules.

The Lab consist of the following systems
1. Wazuh Server: It is used to host the Wazuh.
2. Web Server: It will be the host for a vulnerable site using Docker.
3. Windows Machine: It will be a Windows-based endpoint for monitoring.
4. Kali Linux: It will act as an attacker.
