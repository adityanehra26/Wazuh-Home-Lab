# Web Server
For this home lab, I will be using Debian 13 OS.

For the setup, I will install two things
1. Nginx Proxy
2. Juice-Shop

Both can be installed directly onto the system. But for ease of use, I am going to install using Docker.

## Roadmap
1. Install Docker and Docker Compose
2. Create a docker.yml file
3. Run the machines
4. Install Wazuh-Agent
